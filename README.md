# Data Science Coursework

A collection of undergraduate data science coursework and Python exercises.

## Topics

- Python fundamentals, statistics, and data structures
- Concurrent programming with threads and processes
- Web scraping and data ingestion
- Working with CSV, Excel, JSON, XML, SQL, and MongoDB
- Exploratory analysis and basic machine learning exercises
- Text processing, sentiment analysis, and word clouds

## Repository guide

The files are preserved in their original academic form. A few representative exercises include:

- `CasasCalifornia.py`: housing-data analysis
- `Fake News.py`: text classification exercise
- `P1-Hilos_WebScrapping.py`: concurrent web scraping
- `P4-Titanic.py`: exploratory analysis exercise
- `SQLCONEXION.py` and `06-MongoConnect.py`: database connectivity examples

## Notes

This repository documents coursework and learning exercises rather than a production application. For current master's projects, see the repositories listed in [Proyectos Maestría Ciencia de Datos](https://github.com/TavoVO/Proyectos-Maestr-a-Ciencia-de-Datos).
